# Если шаг не проходит

| Симптом | Что сделать |
| --- | --- |
| `validation.model.import_not_empty` | Метамодель импортируется в пустую модель. Создайте новую и повторите импорт `aiva/metamodel.import.json`. |
| После импорта нет классов C4 | Загружен не тот файл. Нужен `aiva/metamodel.import.json` из этого репозитория. |
| Канвас не сохраняется, `canvas.missing.unit` | Выберите юнит команды у канваса (юниты уже созданы). Если юнита в списке нет, позовите ведущего. |
| Сверка показывает «нет в модели» по всему стенду | Проект ещё черновик. **Сохранить** канвас в репозиторий и подождать привязку класса `container`. |
| В журнале приёма чужие контейнеры | Берёте только записи с меткой `aiva.system` своей команды с карточки. |
| Проверка соединения с Docker не проходит | URL `http://<хост>:50006` с карточки, socket пустой, тип Docker. |
| Нет нормализованных контейнеров | **Распознавание**. Если правило есть, но объектов нет: **В очередь** или процесс bronze → silver в **Процессах**. |
| Отстали на метамодели | Скажите ведущему: он выдаст модель `WS_STEP1`. |
| Отстали на канвасе | Скажите ведущему: он выдаст модель `WS_STEP2`. Продолжайте с **Проверить** и **Сохранить**. |
| MCP: сервер не появился | Опечатка в JSON. |
| MCP: `401` / `unauthorized` | Токен скопирован не целиком или в заголовке нет `Bearer`. |
| MCP: инструменты есть, моделей не видно | Токен от другой организации. |
| MCP: пустой ответ при живой модели | У токена нет права редактора на юнит. Позовите ведущего. |
| `unit_id could not be resolved` | В модели ещё нет объектов и канваса с юнитом. |
