# 3. Метамодель

0:20–0:30. В интерфейс импортируется один файл:

```
aiva/metamodel.import.json
```

Исходников схемы, форм и текстов в этом репозитории нет: они уже внутри import-файла.

1. Откройте свою пустую модель (шаг 1).
2. Вкладка **Общее**.
3. **Импорт метамодели** / **Импорт из JSON**.
4. Выберите `aiva/metamodel.import.json`.
5. Подтвердите.

Появятся слой **C4 Architecture** и классы `person`, `softwareSystem`, `externalSystem`, `container`, `component`. Статусы: Черновик, На согласовании, Согласовано, В эксплуатации, Устаревает, Выведен.

Коды классов совпадают с типами Structurizr. Следующий шаг на это опирается.

Импорт рассчитан на пустую модель. Повторный импорт обновляет настройки по кодам и не удаляет объекты. Если файл лёг криво, создайте новую модель и повторите импорт. Сообщение `validation.model.import_not_empty` значит то же: модель не пустая.

Вместе с метамоделью в файле уже лежат формы, карточки, источник Docker и маппинги в класс `container`. Само подключение к стенду проверяется отдельно, на шаге [05_source.md](05_source.md).

Контрольная точка: слой и пять классов видны. Если отстали — попросите модель `WS_STEP1`.
