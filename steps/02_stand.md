# 2. Стенд магазина

0:00–0:12. Смотрите экран ведущего. Повторно пройти заказ можно самим. Магазин уже развёрнут: собирать его из этого репозитория не нужно.

| Что открыть | URL |
| --- | --- |
| Витрина | `http://<хост>:50000` |
| Статус сервисов | `http://<хост>:50000/status` |
| Outbox писем | `http://<хост>:50004` |

Найдите в поиске «книга», откройте товар, положите в корзину, оформите заказ. После заказа в outbox есть письмо. На `/status` — сервисы, которые сейчас запущены.

Целевую схему на этом шаге не открываем. Список на `/status` не заменяет проект на канвасе.
