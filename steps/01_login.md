# 1. Модель и юнит

0:12–0:20. Подробности входа: [../ACCESS.md](../ACCESS.md).

1. Войдите по URL и логину с карточки. Организация пустая.
2. **Модели → Создать модель**. Код по команде, например `WS_TEAM_07`.
3. **Настройки → Юниты → Создать юнит**. Без юнита канвас не сохранится.

Контрольная точка: своя пустая модель и один юнит.

Дальше: [02_stand.md](02_stand.md), если экскурсию ещё не смотрели, иначе [03_metamodel.md](03_metamodel.md).
