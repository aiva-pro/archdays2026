# 6. Сбор

1:10–1:16.

1. **Интеграции → Источники** → ваш коннектор → **Запустить сейчас**.
2. Откройте **Журнал приёма**. Статусы: получено, смаплено, без правила, ошибка.
3. В записях — контейнеры с меткой `aiva.system` вашей команды. Чужие и служебные без этой метки не берёте.
4. Сверьте список с `http://<хост>:50000/status`.
