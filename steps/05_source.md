# 5. Источник

1:00–1:10. Уровень организации, не внутри модели. Коннектор читает Docker API стенда, порт `50006`, только чтение. Авторизация не нужна.

**Интеграции → Источники** (или **Настройки → Интеграции**).

На подготовленном стенде источник Docker уже может быть. Откройте его и проверьте поля. Если источника нет — **Добавить источник**.

| Поле | Значение |
| --- | --- |
| Тип | Docker |
| Код | например `archdays_docker` |
| Где исполняется | **Облако AIVA**, если стенд доступен по URL; иначе Edge, как скажет ведущий |
| Docker API URL | `http://<хост>:50006` с карточки |
| Unix socket | пусто |
| Что забирать | Containers |

**Проверить соединение**. При создании — **Создать источник**.

Метки на контейнерах стенда уже стоят: `aiva.system` (ваша система на карточке), `aiva.service`, `aiva.c4`, `aiva.kind`, `aiva.tech`, `aiva.owner`, `aiva.version`, `aiva.port`, `aiva.depends_on`.

Контрольная точка: проверка соединения успешна.
