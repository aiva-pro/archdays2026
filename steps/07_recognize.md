# 7. Распознавание

1:16–1:24. Сырая запись Docker ещё не объект модели. Правило раскладывает её в класс `container`.

На стенде правило уже выдано вместе с импортом метамодели. Откройте **Распознавание** и прочитайте его. С нуля собирайте только если готового правила нет.

| Метка | Поле карточки |
| --- | --- |
| `aiva.service` | имя |
| `aiva.tech` | технология |
| `aiva.owner` | команда |
| `aiva.version` | версия |
| `aiva.port` | порт |
| `aiva.description` | описание |
| `aiva.kind` | тип (`API` или веб-приложение) |

Если нормализованных объектов ещё нет: **В очередь** или процесс обработки bronze → silver в **Процессах**.

Контрольная точка: есть нормализованные контейнеры.
