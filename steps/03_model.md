# 3. Создание модели в AIVA

Порядок: вход → подключение к стенду → пустая модель → метамодель → проект на канвасе → сохранение.

Файлы из этого репозитория:

- [files/metamodel.import.json](../files/metamodel.import.json) — метамодель C4
- [files/workspace.dsl](../files/workspace.dsl) — целевой проект (Structurizr DSL, не JSON)

## 1. Вход

1. Откройте URL AIVA с карточки (стенд: https://archdays2026.aiva-pro.tech).
2. Нажмите **Войти** и введите логин и пароль с карточки.
3. Откроется организация команды. Она пустая: моделей, объектов и канвасов ещё нет. Юнит команды уже создан, заводить его не нужно.

## 2. Подключение к стенду

Подключение создаём до импорта метамодели. В файле метамодели лежит датасет для Docker-контейнеров, он привязан к подключению с кодом `ECOM_DOCKER`. Если подключения ещё нет, импорт пропустит датасет, и повторить его в той же модели не получится.

1. В боковой панели переключите режим работы на **Конфиг** и откройте **Интеграции → Подключения**.
2. Нажмите **Добавить подключение**.

| Поле | Значение |
| --- | --- |
| Тип | Docker |
| Код | `ECOM_DOCKER`. Другой код не подойдёт |
| Где исполняется | **Облако AIVA**. Edge-коллектор — только если скажет ведущий |
| Docker API URL | `http://<хост>:50006`, хост на карточке |
| Unix socket | пусто |

3. Дождитесь сообщения «Подключение работает».

Подключение читает Docker API стенда. Доступ только на чтение, авторизация не нужна.

Контрольная точка: подключение `ECOM_DOCKER` работает.

## 3. Пустая модель

1. Вернитесь из интеграций к списку моделей организации: **Модели → Создать модель** (или **Добавить модель**).
2. Название, например `Воркшоп команда 07`. Код: латиница, цифры и `_`, например `WS_TEAM_07`.
3. Нажмите **Создать**.

Модель должна быть пустой: без слоёв и классов. Импорт метамодели принимается только в пустую модель.

## 4. Импорт метамодели

1. Откройте созданную модель → **Конструктор** → вкладка **Общее**.
2. В блоке **Метамодель** нажмите **Импорт из JSON**.
3. Выберите `files/metamodel.import.json` и подтвердите.

Дождитесь сообщения об успехе. Если появилось `validation.model.import_not_empty`, модель не пустая: создайте новую и повторите импорт с шага 3.

Вместе с метамоделью в файле лежат формы, карточки и датасет для Docker-контейнеров.

Если импорт выдал предупреждение `connector "ECOM_DOCKER" not found`, датасет пропущен: проверьте код подключения, создайте новую модель и повторите импорт.

## 5. Проверка метамодели

Вкладка **Структура**: должен быть слой **C4 Architecture** и классы `person`, `softwareSystem`, `externalSystem`, `container`, `component`. На вкладке **Статусы**: Черновик, На согласовании, Согласовано, В эксплуатации, Устаревает, Выведен.

Если классов нет, загружен не тот файл. Если отстали, скажите ведущему: он выдаст модель `WS_STEP1`.

## 6. Канвас

1. В модели откройте **Изменения** → **Создать канвас** (изменение).
2. Название, например `ArchDays Store — целевая`, код, например `WS_C4_TARGET`.
3. Выберите **юнит своей команды**. Без юнита сохранение в репозиторий не пройдёт (`canvas.missing.unit`). Если юнита нет в списке, позовите ведущего.

## 7. Импорт Structurizr

1. Откройте канвас, переключитесь в режим **Таблица** (не режим рисования).
2. Нажмите **Импорт из Structurizr** и выберите `files/workspace.dsl`.
3. Включите **Создать вкладки из Views (Landscape, Container)**. Без этого вкладки представлений не появятся.
4. Нажмите **Импортировать**.

На канвасе появятся покупатель, система ArchDays Store, контейнеры и платёжный провайдер.

### Платёжный провайдер

Найдите **Платёжный провайдер** и проверьте класс: должен быть **External System**. Если стоит **Software System**, смените его на `externalSystem`.

## 8. Проверка

1. Режим рисования: проверьте, что появились вкладки из Views (контекст и контейнеры), на них есть объекты и связи, имена читаются.
2. Нажмите **Проверить**. Закройте ошибки на вкладках «Элементы» и «Связи».

| Проблема | Что сделать |
| --- | --- |
| Нет класса у элемента | метамодель импортирована из `files/metamodel.import.json` |
| Лишняя иерархия или вторая связь там, где допустима одна | оставьте одну связь |
| Канвас не собран, зал ушёл дальше | скажите ведущему: он выдаст модель `WS_STEP2`, продолжайте с проверки |

## 9. Сохранение и статус

1. Если в статусной панели есть **Предложить**, нажмите, когда правки больше не нужны.
2. Нажмите **Сохранить** (в репозиторий) и дождитесь статуса **Сохранено**. Черновик сверка не читает.
3. Проставьте ключевым объектам статус **Согласовано**.

## 10. Проверка в содержимом модели

Откройте **Содержимое модели** (реестр объектов). Должны быть: покупатель, ArchDays Store, контейнеры (`storefront`, `catalog`, `cart`, `orders`, `payments`) и платёжный провайдер.

Контрольная точка: в модели лежит сохранённый проект со статусом Согласовано.
