# 8. Связь с моделью

1:24–1:32. Этот шаг после сохранения проекта. Иначе сопоставлять не с чем.

Сохранение канваса запускает сопоставление с уже собранным фактом. Отдельный ручной прогон для этого не нужен.

1. Откройте **Интеграции → Объекты**.
2. У класса Container виден источник. Совпавшие сервисы связаны с объектами проекта.
3. Фактические значения лежат на обнаруженных объектах. Значения проекта на своих карточках не перезаписываются.

**Привязать всё непривязанное** и **Опубликовать всё готовое** до сверки не нажимайте. Эти кнопки принимают найденный сервис в проект. Их нажимают после сравнения, если команда решила изменить проект.

Если при сохранении канваса вышло предупреждение о сверке, проект уже записан. Повторно не публикуйте. Позовите ведущего.
