# 01. Строка сверки → действие

Общий сценарий зала. Делайте после [../steps/05_reconcile.md](../steps/05_reconcile.md): проект сохранён, факт со стенда связан с моделью, строки вы уже прочитали.

## Просьба агенту

Назовите код своей модели.

> По моей модели сравни проект и то, что принёс коннектор. По каждой строке, где стороны разошлись, скажи, какое действие уместно: задача на развёртывание, правка проекта через канвас или зафиксированное решение ничего не менять. Для задачи на развёртывание заполни шаблон карточки. Для правки проекта предложи объект и связь. Канвас не публикуй.

Если агент просит коды классов, первая фраза: «Сначала выгрузи метамодель».

## Что делает агент

Читает репозиторий и связи. Шаблон задачи на деплой — `TM_CONTAINER_DEPLOY_TASK`. Черновик правки кладёт на канвас. Кнопку «Сохранить» не нажимает.

Агент не запускает сверку в интерфейсе. Он видит то, что уже лежит в репозитории. Если обнаруженных объектов нет, сравнение пустое: вернитесь к [../steps/04_fact.md](../steps/04_fact.md).

## Что делаете вы

Сверяете текст со своими строками. Тикет забираете как есть или правите. Правку проекта открываете на канвасе, жмёте **Проверить**, затем **Сохранить**, если с решением команды она совпала.

## Готово

Есть текст действия по каждой разошедшейся строке. В модель попало только то, что вы сохранили сами.
