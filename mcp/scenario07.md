# 07. Код изменился — архитектуру сохранить

Разработчик добавил вызов, которого нет в согласованном проекте. Задача агента — прочитать правку и подготовить изменение архитектуры. В репозиторий AIVA оно попадает только после **Проверить** и **Сохранить**.

Общий стенд этой правкой не обновляйте. Делайте после сверки, на своей модели, не на `WS_STEP1` / `WS_STEP2`. Новый контейнер — отдельное решение, не подмена строк, которые вы уже разобрали.

Кода магазина в этом репозитории нет. Ниже вся правка, которую нужно иметь в виду. В общий стенд она не выкладывается.

## Шаг 1. Правка в коде

В `services/catalog/src/server.js` каталог начинает запрашивать рекомендации. Без `RECOMMENDATIONS_URL` маршрут отвечает пустым списком.

```js
dependsOn: ["recommendations"],
```

```js
const RECOMMENDATIONS_URL = process.env.RECOMMENDATIONS_URL || "";

app.get("/products/:id/related", async (req, reply) => {
  const product = products.find((p) => p.id === req.params.id);
  if (!product) return reply.code(404).send({ error: "product_not_found" });
  if (!RECOMMENDATIONS_URL) return { productId: product.id, items: [] };
  const res = await fetch(
    `${RECOMMENDATIONS_URL}/related?productId=${encodeURIComponent(product.id)}`,
  );
  if (!res.ok) return reply.code(502).send({ error: "recommendations_unavailable" });
  return res.json();
});
```

## Шаг 2. Просьба агенту

> Прочитай diff `services/catalog/src/server.js`. Какой новый вызов появился в коде? Есть ли цель этого вызова в согласованном проекте? Если нет — добавь на канвас контейнер и связь от catalog отношением «Использует контейнер». Технологию и команду возьми из кода, не выдумывай. Статус нового объекта — Черновик. Канвас не публикуй, пока я не посмотрю.

Коды классов и отношений агент берёт из метамодели. Нужная связь — `C4_CONTAINER_USES_CONTAINER`.

## Шаг 3. Сохранить архитектуру

Откройте канвас.

1. Контейнер рекомендаций есть, связь идёт от `catalog`, не от случайного сервиса.
2. Уже согласованные контейнеры на месте.
3. **Проверить**.
4. **Сохранить**, если команда принимает изменение.
5. Статус нового контейнера оставьте **Черновик** или переведите в **На согласовании**. **Согласовано** ставите отдельным решением, не фактом коммита.

## Готово

Правка кода и запись в архитектурный репозиторий — два разных шага, и второй вы закрыли сами. Пока контейнер не развёрнут, на следующей сверке он будет в проекте и отсутствовать на стенде. Это ожидаемое следствие сценария.
