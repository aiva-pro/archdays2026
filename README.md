# ArchDays 2026 — материалы участника воркшопа

Задача занятия: проверить, соответствует ли реализация магазина архитектурному проекту.

Здесь только то, что нужно в зале: метамодель, целевая схема и порядок действий. Кода магазина, секретов и заметок ведущего нет. Логин, пароль и токен выдаются отдельно, на карточке. По любым вопросам обращайтесь к ведущим.
