# ArchDays × AIVA — материалы участника

Здесь только то, что нужно в зале: метамодель, целевая схема и порядок действий. Кода магазина, секретов и заметок ведущего нет. Логин, пароль и токен — на карточке.

## Стенды

| Стенд | Ссылка |
| --- | --- |
| Aiva, ArchDays | https://archdays2026.aiva-pro.tech |
| Магазин | https://ecomarch.aiva-pro.tech |
| Статус сервисов магазина | https://ecomarch.aiva-pro.tech/status |
| Письма после заказа | https://ecomarch.aiva-pro.tech/outbox/ |

К концу занятия в вашей модели есть проект магазина, факт со стенда и прочитанное сравнение. Состав строк сверки заранее не сообщается.

## Расписание зала

Это час из раздатки. По нему идут шаги ниже.

| Время | Что делаем | Куда |
| --- | --- | --- |
| 0:00–0:12 | Экскурсия: витрина, заказ, `/status`, письма | [steps/02_stand.md](steps/02_stand.md) |
| 0:12–0:20 | Вход, пустая модель, юнит | [steps/01_login.md](steps/01_login.md) |
| 0:20–0:30 | Импорт метамодели | [steps/03_metamodel.md](steps/03_metamodel.md) |
| 0:30–1:00 | Схема на канвас, проверка, сохранение, статус Согласовано | [steps/04_canvas.md](steps/04_canvas.md) |
| 1:00–1:32 | Источник, сбор, распознавание, связь с моделью | [steps/05_source.md](steps/05_source.md) … [steps/08_link.md](steps/08_link.md) |
| 1:32–1:42 | Сверка | [steps/09_reconcile.md](steps/09_reconcile.md) |
| 1:42–1:55 | Свой агент | [mcp/README.md](mcp/README.md) |
| 1:55–2:00 | В модели остаются язык, проект, факт и ваше решение по строкам | |

До чтения сверки не нажимайте **Привязать всё непривязанное** и **Опубликовать всё готовое**.

Идите по таблице выше. Если отстали — [ACCESS.md](ACCESS.md).

## Что открывать в интерфейсе

```
экскурсия → модель и юнит → метамодель → проект на канвасе → сохранение
→ источник → сбор → распознавание → связь с моделью → сверка → агент
```

| Файл | Зачем |
| --- | --- |
| [aiva/metamodel.import.json](aiva/metamodel.import.json) | единственный файл импорта метамодели |
| [c4/target/workspace.dsl](c4/target/workspace.dsl) | целевая схема для канваса |
| [CREDENTIALS.md](CREDENTIALS.md) | какие поля приходят на карточке, без значений |
| [troubleshooting.md](troubleshooting.md) | если шаг не проходит |

## Агент

Подключение: [mcp/README.md](mcp/README.md). В зале все делают [mcp/scenario01.md](mcp/scenario01.md). Если агент ещё не отвечает по модели, сначала [mcp/scenario02.md](mcp/scenario02.md). Остальные — по одному на команду, если осталось время. Формулировки: [mcp/cheatsheet.md](mcp/cheatsheet.md).

Агент читает модель и готовит текст. **Сохранить** на канвасе нажимаете вы.
