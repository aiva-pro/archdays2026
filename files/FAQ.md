# FAQ

| Симптом | Что сделать |
| --- | --- |
| `validation.model.import_not_empty` | Метамодель импортируется в пустую модель. Создайте новую и повторите импорт `files/metamodel.import.json` (см. [шаг 3](../steps/03_model.md)). |
| После импорта нет классов C4 | Нужен `files/metamodel.import.json` из этого репозитория. |
| Канвас не сохраняется, `canvas.missing.unit` | Выберите юнит своей команды в канвасе. Юниты созданы заранее: если его нет в списке, позовите ведущего. |
| На сверке нет объектов проекта | Проект не сохранён. Нажмите **Сохранить** на канвасе. |
| Все записи стенда в статусе «Ожидает» | Маппинг не запущен. **Входящие → Маппинги** → маппинг `container` → **Запуски** → **Привязать всё непривязанное**. |
| В логе сбора чужие контейнеры | Берём только записи с меткой `aiva.system` своей команды. |
| Проверка подключения Docker не проходит | URL Docker API с карточки, socket пустой, тип Docker. |
| В датасете нет записей контейнеров | Проверьте, что код подключения — `ECOM_DOCKER`. Затем в датасете откройте вкладку **Обработка** и нажмите **Обработать сейчас**. |
| Отстали на метамодели | Попросите модель `WS_STEP1`. |
| Отстали на канвасе | Попросите модель `WS_STEP2` и продолжайте с **Проверить** и **Сохранить**. |
| MCP: сервер не появился | Опечатка в JSON. |
| MCP: `401` / `unauthorized` | Токен скопирован не целиком или в заголовке нет `Bearer`. |
| MCP: инструменты есть, моделей не видно | Токен от другой организации. |
| MCP: пустой ответ при живой модели | У токена нет права редактора на юнит. Позовите ведущего. |
| `unit_id could not be resolved` | В модели ещё нет объектов и канваса с юнитом. |
